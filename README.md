# AlexPDF для muOS

Лёгкая и быстрая программа для чтения PDF-документов и комиксов на портативных ретро-консолях под управлением **MustardOS (muOS)**. Написана на Python с использованием **Pygame** и **PyMuPDF (`fitz`)**.

## Возможности

* **Встроенный файловый менеджер:** Навигация по вложенным папкам и быстрое переключение между внутренней картой памяти (`SD1` / `/mnt/mmc`) и второй картой (`SD2` / `/mnt/sdcard`).
* **Два режима чтения:** Классический постраничный просмотр и непрерывная вертикальная лента для удобного чтения длинных документов и веб-комиксов.
* **Четыре темы оформления:** *Тёмная*, *Светлая*, *Ночь (инверсия цветов страницы)* и *Сепия* (применяются как к интерфейсу, так и к рендеру PDF).
* **Поворот экрана на 90°:** Поворот интерфейса и страниц (`0°`, `90°`, `180°`, `270°`) с автоматической переориентацией крестовины.
* **Автосохранение прогресса:** Запоминает последнюю открытую страницу для каждой книги, текущую папку, тему, режим чтения и угол поворота в `alexpdf_state.json`.
* **Встроенная справка:** Всплывающая подсказка по всем горячим клавишам прямо внутри приложения.

## Управление

| Кнопка | В файловом менеджере | В режиме чтения PDF |
| :--- | :--- | :--- |
| **Крестовина (D-Pad)** | Выбор файла или папки | Прокрутка страницы / непрерывной ленты |
| **SELECT** | Открыть папку или PDF-файл | Циклическое изменение масштаба (`100%` → `150%` → `200%`) |
| **A** | Открыть папку или PDF-файл | Следующая страница (`+1`) |
| **B** | Перейти на папку выше | Предыдущая страница (`-1`) |
| **X / Y** | — | Быстрая перемотка (`+10` / `-10` страниц) |
| **L1** | — | Переключить режим: **Постранично / Непрерывно** |
| **R1** | Показать / скрыть справку | Показать / скрыть справку |
| **L2** | Сменить тему оформления | Сменить тему оформления |
| **R2** | Повернуть экран на `90°` | Повернуть экран на `90°` |
| **MENU** | — | Вернуться к списку файлов |
| **MENU + START** | Выход из приложения | Выход из приложения |

## Установка на консоль (готовый релиз)

1. Скачайте готовый установочный архив **`AlexPDF.muxapp`** из раздела [Releases](../../releases).
2. Скопируйте `AlexPDF.muxapp` на SD-карту консоли в папку **`/ARCHIVE/`**.
3. На консоли откройте **Applications → Archive Manager**, выберите `AlexPDF.muxapp` и нажмите кнопку подтверждения для установки.
4. Поместите ваши PDF-файлы в папку `/mnt/mmc/ROMS/PDF` (или в любую другую папку на `SD1` / `SD2`).

## Сборка из исходников

Для упаковки установочного пакета `.muxapp` с библиотеками под архитектуру **ARM64 (`aarch64`)** используйте скрипт `build.sh` на ПК с Linux или в среде WSL:

```bash
chmod +x build.sh
./build.sh
```

Скрипт автоматически создаст структуру приложения, загрузит совместимые с `manylinux2014_aarch64` пакеты `pygame` и `PyMuPDF` в каталог `site-packages/` и соберёт готовый архив **`AlexPDF.muxapp`**.

### Параметры сборки
Если в вашей версии прошивки muOS используется Python 3.12 (проверяется командой `python3 --version` на консоли), передайте версию как аргумент при запуске скрипта:

```bash
./build.sh 3.12
```
